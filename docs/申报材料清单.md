**第二步：推送**

```bash

# 推送前再确认一次：没有任何文件超过 50 MB
git ls-files -z | xargs -0 du -m | sort -rn | head -5
```

**第三步：仓库设置**

`git rev-list --objects --all | git cat-file --batch-check='%(objecttype) %(objectname) %(objectsize) %(rest)' | sort -k3 -n | tail -5`
定位，再用 `git filter-repo` 清理。当前仓库不应触发该错误。
